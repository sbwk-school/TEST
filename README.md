# เว็บแอปตรวจข้อสอบออนไลน์ 4 ตัวเลือก (OMR Exam Scanner)

เว็บแอปพลิเคชันตรวจข้อสอบแบบ 4 ตัวเลือก (ก ข ค ง หรือ 1 2 3 4) ทำงานบนเบราว์เซอร์ 100% ออกแบบมาสำหรับคุณครูและอาจารย์ สามารถสร้างกระดาษคำตอบ นำไปวางใน Microsoft Word เพื่อพิมพ์ให้นักเรียนสอบ บันทึกเฉลยได้หลายวิชา และใช้กล้องมือถือส่องตรวจแสดงคะแนนทันที พร้อมเชื่อมต่อฐานข้อมูล Firebase Firestore และรองรับ Firebase Hosting

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **📄 ขอตารางกระดาษคำตอบ (4 ช่อง/ตัวเลือก)**
   - กำหนดจำนวนข้อสอบได้ตามต้องการ: 10, 20, 30, 40, 50, 60, 80, 100 ข้อ
   - เลือกชนิดตัวเลือก: **ก ข ค ง**, **1 2 3 4**, หรือ **A B C D**
   - **มีจุดมาร์คสี่เหลี่ยมดำ 4 มุม (Corner Fiducials)** ที่ออกแบบให้กล้องจับพิกัดและดึงระนาบตรงอัตโนมัติ
   - ปุ่ม **"คัดลอกภาพไปใส่ Word"**: กดปุ่มเดียวแล้วเปิด Microsoft Word กด `Ctrl + V` ได้ทันที
   - รองรับการดาวน์โหลดไฟล์ภาพ PNG ความละเอียดสูง และการสั่งพิมพ์ A4 / บันทึกเป็น PDF

2. **🔑 ระบบจัดการเฉลยหลายวิชา (Multi-Subject Answer Keys)**
   - บันทึกเฉลยแยกตามรายวิชาและห้องเรียน (เช่น "วิทยาศาสตร์ ม.1/1", "คณิตศาสตร์ ม.3")
   - สลับเลือกวิชาที่ต้องการตรวจได้สะดวกรวดเร็ว
   - มีปุ่มเพิ่มวิชาใหม่ แก้ไขจำนวนข้อ ล้างคำตอบ และสุ่มเฉลยสำหรับทดสอบ
   - บันทึกข้อมูลลงใน **Firebase Firestore** แบบเรียลไทม์ (พร้อมสำรองใน `LocalStorage` เมื่อออฟไลน์) ตรวจไม่เสร็จก็กลับมาตรวจต่อได้

3. **📷 ระบบตรวจข้อสอบด้วยกล้องมือถือ (Real-time Camera Scanner)**
   - เปิดกล้องมือถือส่องกระดาษคำตอบ (สลับกล้องหน้า/หลังได้)
   - ระบบ Computer Vision ตรวจจับจุดมาร์ค 4 มุม และปรับมุมมองภาพ (Perspective Warp) ให้ตรง
   - วิเคราะห์รอยฝนดินสอ/ปากกาในแต่ละวงกลม และเปรียบเทียบกับเฉลย
   - **แสดงคะแนนทันที (Instant Score HUD)**: แสดงคะแนนใหญ่ชัดเจน, สรุปข้อถูก/ผิด/ไม่กา, และตารางผลรายข้อ
   - มีเสียง Beep ตอบรับเมื่อตรวจพบและตรวจเสร็จ
   - มีปุ่ม **"ทดสอบตรวจกระดาษจำลอง" (Simulator)** ให้ลองตรวจได้ทันทีโดยไม่ต้องปรินต์กระดาษจริง

4. **🔥 เชื่อมต่อ Firebase & Hosting**
   - ตั้งค่า Firebase Project Key ได้ง่ายๆ ผ่านหน้าเว็บในแท็บ "ตั้งค่า Firebase"
   - มีไฟล์ `firebase.json` และ `.firebaserc` พร้อมสำหรับ Deploy ขึ้น Firebase Hosting

## 🚀 วิธีการใช้งาน

### 1. การเปิดใช้งานทั่วไป
- คุณสามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge, Safari, Firefox) เพื่อใช้งานได้ทันที
- หรือเปิดผ่าน Local Web Server (เช่น `Live Server` ใน VS Code)

### 2. ขั้นตอนการทำกระดาษคำตอบไปใช้ใน Microsoft Word
1. ไปที่แท็บ **"สร้างกระดาษคำตอบ"**
2. เลือกจำนวนข้อ และใส่ชื่อวิชา/ห้องเรียนตามต้องการ
3. คลิกปุ่ม **"📋 คัดลอกภาพไปใส่ Word (Ctrl+V)"**
4. เปิดโปรแกรม **Microsoft Word** แล้วกด **Ctrl + V** เพื่อวางรูปภาพ
5. พิมพ์กระดาษแจกนักเรียนเพื่อทำการสอบ (แนะนำให้นักเรียนใช้ดินสอดำ 2B หรือปากกาสีน้ำเงิน/ดำ ฝนให้เต็มวง)

### 3. ขั้นตอนการใส่เฉลย
1. ไปที่แท็บ **"จัดการเฉลยวิชา"**
2. คลิก **"+ เพิ่มวิชาใหม่"** หรือเลือกวิชาจากรายการด้านซ้าย
3. กำหนดชื่อวิชา, ห้อง, และจำนวนข้อ
4. คลิกที่ตัวเลือก (ก ข ค ง) ของแต่ละข้อเพื่อกำหนดเฉลยที่ถูกต้อง
5. คลิกปุ่ม **"💾 บันทึกชุดเฉลย"**

### 4. ขั้นตอนการสแกนตรวจข้อสอบ
1. ไปที่แท็บ **"ตรวจข้อสอบด้วยกล้อง"**
2. ตรวจสอบว่ากำลังตรวจในวิชาที่ต้องการ (ดูที่แถบด้านบน)
3. คลิก **"📷 เปิดกล้องตรวจ"** (อนุญาตให้เบราว์เซอร์เข้าถึงกล้อง)
4. เล็งกล้องไปที่กระดาษคำตอบ ให้ **จุดมาร์คสี่เหลี่ยมดำทั้ง 4 มุม** อยู่ในกรอบ
5. เมื่อกล้องจับจุดมาร์คได้ครบ ระบบจะส่งเสียง **Beep** และแสดงคะแนนบนหน้าจอทันที!
6. คลิก **"ตรวจใบต่อไป ➔"** เพื่อตรวจกระดาษของนักเรียนคนถัดไป

## ☁️ การนำขึ้น Firebase Hosting & ตั้งค่า Backend

หากต้องการนำเว็บแอปนี้ขึ้นโฮสติ้งจริงของ Firebase:

1. ติดตั้ง Firebase CLI (หากยังไม่มี):
   ```bash
   npm install -g firebase-tools
   ```
2. เข้าสู่ระบบ Firebase:
   ```bash
   firebase login
   ```
3. เชื่อมโยงโปรเจกต์:
   ```bash
   firebase use --add
   ```
4. สั่ง Deploy ขึ้น Firebase Hosting:
   ```bash
   firebase deploy --only hosting
   ```
5. เมื่อ Deploy เสร็จ นำค่า Firebase Config (จาก Firebase Console -> Project Settings -> Your Apps) ไปใส่ในแท็บ **"ตั้งค่า Firebase"** เพื่อเปิดใช้ระบบฐานข้อมูล Firestore ออนไลน์
